Install and register

  1. Extract the ZIP and open Bearings.app in the account that should send reports.
  2. Choose Register and enable reports, then paste your organization's rollout key. Obtain a key from your administrator{% if client_rollout_allowed %} or open Rollout keys if you manage them{% endif %}.
  3. Use Check report status to verify registration and delivery. Applied means the report was processed on the server.

Rollout and periodic reports

Install as the account that will send reports. Bearings installs the app in ~/Applications and registers a LaunchAgent that runs at sign-in and every 15 minutes while signed in. The Mac reports changes and sends compact check-ins when its inventory stays the same.

For managed rollout, supply the rollout key on standard input through your deployment secret manager and run the following as the reporting user.

./Bearings.app/Contents/MacOS/bearings-macos install

Update and uninstall

The installed app verifies and installs signed client releases from this Bearings server. Use Check for client update to check immediately. Automatic client updates can be turned off in the app. Use Uninstall in the app or request retirement in Bearings to deregister and remove it during a scheduled run.
