Single-host enrollment (advanced)

Approve one existing or managed host

  1. Download the installer over verified HTTPS:
    curl --fail --show-error --proto '=https' '{{ origin }}/downloads/linux/install.py' -o bearings-install.py
  2. Review it, then install:
    sudo python3 bearings-install.py --server '{{ origin }}'
    The installer downloads the matching architecture, checks the manifest, creates the dedicated account and shows its public key.
  3. In your company's Client inventory observations, paste that public key and approve the existing/new host. Copy the one-use registration code.
  4. On the server:
    sudo python3 bearings-install.py enroll --code
    Paste the code at the hidden prompt. No registration files need to cross your SSH connection.

Installer · Checksums · Corresponding source · License

Updates use the same install command. Device keys and queued observations remain. Files are operator-built reference artifacts; checksums are not release signatures. Custom CA trust is supported with --ca-file; certificate verification is always required.

Uninstall

Run sudo python3 install.py uninstall on the host. An administrator can also choose Deregister and uninstall for the device in Inventory reports. The timer installed by the current installer checks for the request.
