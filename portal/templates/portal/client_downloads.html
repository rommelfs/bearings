Automatic company registration

In your company’s Linux inventory reports → Automatic registration / fleet rollout, create one rollout key with an expiry and device limit. Each host generates its own key; no per-host public-key copy is needed.

curl --fail --show-error --proto '=https' '{{ origin }}/downloads/linux/install.py' -o bearings-install.py
sudo python3 bearings-install.py --server '{{ origin }}' --bootstrap-prompt

Paste the rollout key at the hidden prompt. For your deployment process use --bootstrap-stdin and pass it from your secret manager through stdin. Add --lxc-compatible on constrained LXC hosts. New hosts remain self-reported Bearings observations; they do not acquire NetBox write permissions.

Alternative: approve one existing or managed host

  1. Download the installer over verified HTTPS:
    curl --fail --show-error --proto '=https' '{{ origin }}/downloads/linux/install.py' -o bearings-install.py
  2. Review it, then install:
    sudo python3 bearings-install.py --server '{{ origin }}'
    The installer downloads the matching architecture, checks the manifest, creates the dedicated account and shows its public key.
  3. In your company's Linux inventory reports, paste that public key and approve the existing/new host. Copy the one-use registration code.
  4. On the server:
    sudo python3 bearings-install.py enroll --code
    Paste the code at the hidden prompt. No registration files need to cross your SSH connection.
