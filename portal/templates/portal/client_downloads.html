Install the Bearings Linux client

Download directly on your Linux server. You need Python 3.9+, systemd and sudo; no Go compiler is needed on the monitored machine. Trust this installation's HTTPS certificate first.

{% if ready %}
  1. Download the installer over verified HTTPS:
    curl --fail --show-error --proto '=https' '{{ origin }}/downloads/linux/install.py' -o bearings-install.py
  2. Review it, then install:
    sudo python3 bearings-install.py --server '{{ origin }}'
    The installer downloads the matching architecture, checks the manifest, creates the dedicated account and shows its public key.
  3. In your company's Linux inventory reports, paste that public key and approve the existing/new host. Copy the one-use registration code.
  4. On the server:
    sudo python3 bearings-install.py enroll --code
    Paste the code at the hidden prompt. No registration files need to cross your SSH connection.
