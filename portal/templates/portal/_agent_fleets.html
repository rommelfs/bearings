Automatic Linux registration · {{ org.name }}

Approve a rollout once and distribute its limited key through your deployment secret manager. Each installed host generates its own device key and registers itself; repeat installation keeps the identity. No per-host public-key copy, NetBox entry or enrollment code is needed.

Each rollout records its inventory mode: Bearings only, or Managed NetBox when enabled by the platform operator. Existing rollout keys retain their original mode. Hostnames and IPs do not prove ownership and never attach a new key to an existing asset. Observed-only hosts remain distinct observations. Managed registration requires a new hostname or an explicit existing-asset selection. The rollout key cannot read inventory, replace existing devices or change connector permissions. Managed registration uses only the operator-enabled NetBox connection; read-only sources remain read-only.
