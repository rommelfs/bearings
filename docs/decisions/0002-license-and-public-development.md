# ADR 0002: Public development under AGPL-3.0-or-later

Status: accepted by the owner. Date: 2026-10-16.

The owner explicitly clarified that Bearings must be an open-source project from start to finish and selected the SPDX identifier AGPL-3.0-or-later. This supersedes the initial private-repository wording in the assignment.

Keep `rommelfs/bearings` public. Apply the GNU Affero General Public License version 3 or, at the recipient's option, any later version. Include the full license text in LICENSE, declare the exact SPDX expression in package metadata, retain the license in the development container, and expose source/license links in the web interface. Contributions must be license-compatible, with third-party notices retained as required. No copyright ownership or assignment is invented.

Public source and backlog publication does not authorize deployment, release of organization data, real notifications or scanning. Those operational boundaries remain unchanged. Review dependency and upstream data notices when distributing artifacts; upstream software keeps its own license.
