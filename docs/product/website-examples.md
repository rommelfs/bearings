# Website vulnerability examples and fictional quotes

Reviewed 19 November 2026. These examples explain the value of maintained inventory and reachable owners. They do not assert that a Bearings customer is affected, that Bearings prevented an incident, or that automatic matching proves affectedness. Quotes are deliberately invented personifications, visibly labeled as fiction in every language. There are no invented customer testimonials or vendor endorsements.

| Example | Verified historical fact | Evidence | Bearings benefit illustrated |
| --- | --- | --- | --- |
| NGINX2Root, CVE-2026-123007 and four related CVEs | The current NGINX security list covers the five bugs; Red Hat published its NGINX2Root bulletin on 19 November 2026 after the 18 November disclosure. | [NGINX security advisories](https://nginx.org/en/security_advisories.html), [Red Hat bulletin](https://access.redhat.com/security/vulnerabilities/RHSB-2026-019) | Identify recorded NGINX packages/versions and check enabled features and vendor/distribution fixes. |
| Java / Java4Shell, CVE-2026-114938 | Oracle published its relevant update on 17 November 2026; the CISA alert calls for finding affected Java runtimes, including bundled ones. | [Oracle November update](https://www.oracle.com/security-alerts/cspunov2026.html), [CISA alert, 17 November](https://content.govdelivery.com/accounts/USDHSCISA/bulletins/4332a87) | Record runtime vendor/build and responsible application/team rather than assume every Java installation is equally affected. |
| Cisco Secure FMC, CVE-2026-20079 | Cisco describes authentication bypass and reports awareness of active exploitation in August 2026; CISA added it on 9 September 2026. | [Cisco advisory](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-onprem-fmc-authbypass-5JPp45V2), [CISA bulletin, 9 September](https://content.govdelivery.com/accounts/USDHSCISA/bulletins/42944e2) | Find recorded management products/versions, review the evidence and assign an accountable owner. |
| React Server Components, CVE-2025-55182 | React disclosed unauthenticated remote code execution on 3 December 2025. | [React security announcement](https://react.dev/blog/2025/12/03/critical-security-vulnerability-in-react-server-components) | Record the actual server component/package version rather than assume every React installation is affected. |
| FortiCloud SSO, CVE-2026-24858 | CERT-FR relayed active exploitation on 28 January 2026 and identifies Fortinet advisory FG-IR-26-060 dated 27 January. | [CERT-FR notice](https://cert.cyber.gouv.fr/avis/CERTFR-2026-AVI-0097/), [Fortinet incident update](https://www.fortinet.com/blog/psirt-blogs/analysis-of-sso-abuse-on-fortios), [referenced Fortinet advisory](https://www.fortiguard.com/psirt/FG-IR-26-060) | Locate appliances/firmware, verify the relevant FortiCloud SSO condition and reach the responsible person. |

The React source also documents later related issues and advises following current version guidance. The website therefore avoids fixed-version recommendations and a blanket “all React” claim. The Fortinet public advisory returned HTTP 403 to the research client; the factual summary was corroborated with the accessible official CERT-FR notice and Fortinet's own incident update. The site links the accessible CERT-FR source rather than claiming a successful live advisory fetch.

The short source-derived factual summaries remain separate from original marketing explanations and fictional quotes. Sources are dated historical references, not a live threat feed, a complete list of recent vulnerabilities or legal remediation deadlines for Luxembourg firms. No exploit payload, scan, target list, live company example or new application CVE data was created.

NGINX2Root is a family: CVE-2026-123007, CVE-2026-123633, CVE-2026-123634, CVE-2026-121810 and CVE-2026-113425. The site does not equate the NGINX flaws alone with guaranteed root access or confuse a separately demonstrated kernel privilege-escalation chain with the NGINX CVEs. Java coverage does not imply that every JDK vendor, architecture or build is affected, and Bearings does not automatically discover embedded runtimes. These facts remain explicit inventory/review work.

The current NGINX2Root and Java cards additionally link the operator’s own published analysis: [CIRCL TR-105](https://www.circl.lu/pub/tr-105/) and [CIRCL TR-104](https://www.circl.lu/pub/tr-104/), both listed by CIRCL on 18 November 2026. The site does not copy their exploit/reproducer details or patch tables.
